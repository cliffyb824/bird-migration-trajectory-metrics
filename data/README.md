# Data Folder

Raw and processed data files are not redistributed in this repository.

## Source Dataset

The analysis uses the public `LBBG_ZEEBRUGGE` lesser black-backed gull tracking
dataset from INBO:

<https://ipt.inbo.be/resource?r=lbbg_zeebrugge>

Direct Darwin Core Archive:

<https://ipt.inbo.be/archive.do?r=lbbg_zeebrugge&v=1.3>

## Local Structure

- `raw/`: downloaded Darwin Core Archive files.
- `external/`: downloaded map layers, such as Natural Earth coastlines.
- `processed/`: standardized tracking tables, route segments, distance matrices,
  and summary CSV files generated by the scripts in `src/`.

## Reproducibility

Run the acquisition and processing scripts from the project root after installing
the Python requirements:

```powershell
python src/download_lbbg.py
python src/standardize_dwca.py
python src/segment_migration.py
python src/trim_transit_segments.py
```

The experiment-specific scripts in `src/` then regenerate the processed tables
and figures used by the manuscript.
