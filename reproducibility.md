# Reproducibility Guide

This document records the current workflow for reproducing the prototype results.

## Environment

Tested locally with:

- Python 3.12
- NumPy
- Matplotlib
- SciPy
- scikit-learn

The raw preprocessing scripts use only the Python standard library where possible. Plotting and clustering require the packages above.

Install Python dependencies with:

```powershell
pip install -r requirements.txt
```

## Folder Structure

- `data/raw/`: downloaded Darwin Core Archive and extracted raw tables.
- `data/external/`: downloaded map reference data, including Natural Earth coastline files.
- `data/processed/`: standardized data, candidate segments, distance matrices, and experiment outputs.
- `src/`: analysis scripts.
- `figures/`: generated PNG figures.
- `manuscript/`: manuscript draft and paper notes.
- `references/`: literature and dataset notes.

## Core Pipeline Shortcut

After the raw archive is downloaded and extracted, the main current outputs can be regenerated with:

```powershell
python src\run_core_pipeline.py
```

This runs standardization, segmentation, season splitting, the main robustness experiments, the main perturbation experiments, the 50-route distance prototype, anomaly scoring, and the current figures.

The current core pipeline uses transit-focused segments generated by `src\trim_transit_segments.py`.

The route overview figure uses the Natural Earth 1:110m coastline. The core pipeline downloads this layer with `src\download_naturalearth.py`; the plotting script can still run without it, but the output will be a plain longitude-latitude map.

## Step 9b: Run Season-Aware Perturbation Intensity Sweep

The publication-oriented perturbation sweep covers every transit-focused route
with at least 80 points in each season. It retains absolute distances and also
normalizes each metric by its trajectory-specific mean response to the strong
time-warp controls (`gamma=0.4` and `gamma=2.5`). The normalized responses
should be used when comparing sensitivity patterns across metrics with
different scales.

```powershell
python src\shape_perturbation_sweep.py --input data\processed\lbbg_zeebrugge_transit_spring_candidate_segments.csv --season spring --output data\processed\shape_perturbation_sweep_spring.csv --summary data\processed\shape_perturbation_sweep_spring_summary.csv --n-points 80 --min-points 80
python src\shape_perturbation_sweep.py --input data\processed\lbbg_zeebrugge_transit_autumn_candidate_segments.csv --season autumn --output data\processed\shape_perturbation_sweep_autumn.csv --summary data\processed\shape_perturbation_sweep_autumn_summary.csv --n-points 80 --min-points 80
python src\plot_shape_perturbation_sweep.py --input data\processed\shape_perturbation_sweep_spring_summary.csv data\processed\shape_perturbation_sweep_autumn_summary.csv --output figures\shape_perturbation_sweep_relative.png
```

Current result:

- smoothing windows: 3, 7, 11, 15, 21
- local-detour amplitudes: 0.01, 0.02, 0.04, 0.06, 0.08
- local-loop amplitudes: 0.01, 0.02, 0.04, 0.06, 0.08

Outputs:

## Current Main Result

The strongest current result is the combination of:

1. batch time-warp robustness;
2. batch shape-perturbation response.

Across 20 candidate spring migration trajectories:

- pointwise L2 distance increases substantially under artificial time warping;
- raw-coordinate DTW is strongest for pure time-warp invariance;
- direct SRVF remains sensitive to sampling alignment;
- SRVF-DTW remains robust to time warping and provides a distinct
  velocity-shape response profile.

Main figure:

`figures/timewarp_robustness_transit_batch.png`

Second main figure:

`figures/shape_perturbation_transit_batch.png`

## Known Limitations

1. Candidate migration segmentation is heuristic.
2. Spherical resampling uses chord-length interpolation, not geodesic interpolation.
3. SRVF-DTW is a practical approximation, not full elastic SRVF registration.
4. Clustering results are exploratory and not currently strong enough to support superiority claims.
