\begin{abstract}
Animal tracking datasets often contain irregular sampling and prolonged observation gaps, yet migration routes are commonly compared after reducing each incomplete track to a single deterministic curve. This study presents a validate--calibrate--propagate diagnostic for assessing how missing-route uncertainty affects trajectory-distance analyses of bird migration routes. Transit-focused routes from open GPS tracking data for Lesser Black-backed Gulls (\emph{Larus fuscus}) were embedded on the unit sphere and compared using raw-coordinate dynamic time warping (DTW) and DTW-aligned square root velocity function (SRVF-DTW) distances. Controlled missingness experiments contrasted random point loss with contiguous tracking gaps. Deterministic spherical bridge interpolation was compared with an estimated-scale Brownian bridge reconstruction that samples plausible paths inside missing intervals. Reconstruction envelopes were validated against withheld observed route segments, empirically calibrated through radius inflation toward nominal 90\% coverage, and then propagated to distance matrices, route clustering, anomaly ranking, and top-ranked anomaly overlap. Random point loss had limited effect after resampling, whereas contiguous gaps substantially altered clustering and anomaly diagnostics. In a season-aware Brownian bridge experiment, estimated perturbation scales differed between spring and autumn routes, and downstream stability depended on both route metric and season. Withheld-segment validation showed that the Brownian bridge baseline was not fully calibrated for true-path recovery before radius inflation. These findings support validated and calibrated uncertainty diagnostics as a practical diagnostic step for route comparison under prolonged tracking gaps, while the biological results remain specific to the gull dataset analyzed here.
\end{abstract}

\section*{Data availability}
The GPS tracking data used in this study are publicly available from the
\texttt{LBBG\_ZEEBRUGGE} occurrence dataset published by the Research Institute
for Nature and Forest (INBO). The dataset is available through the INBO IPT at
\url{https://ipt.inbo.be/resource?r=lbbg_zeebrugge} and is released under a CC0
1.0 license. The version used in this study is version 1.3.

\section*{Code availability}
The analysis code used for preprocessing, candidate migration segmentation,
distance computation, missing-data experiments, reconstruction diagnostics, and
figure generation is
available at
\url{https://github.com/cliffyb824/bird-migration-trajectory-metrics}. Raw GPS
tracking data are not redistributed with the code and should be obtained from
the public \texttt{LBBG\_ZEEBRUGGE} dataset.
