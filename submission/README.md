# Ecological Informatics Submission Package

LaTeX submission files for the manuscript:

**Uncertainty-Aware Comparison of Migratory Routes from Incomplete Animal
Tracking Data**

The source package is in `submission/latex/`. Build it with:

```powershell
powershell -ExecutionPolicy Bypass -File submission\latex\build.ps1
```

Expected output:

- `submission/latex/main.pdf`

The current submission package is intentionally minimal: manuscript source,
references, highlights, and the generated main PDF. Main figures are referenced
from the project-level `figures/` directory.

Public code repository:

<https://github.com/cliffyb824/bird-migration-trajectory-metrics>
