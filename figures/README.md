# Figures

Current main manuscript figures:

1. `uncertainty_framework_figure.png`
   - Workflow schematic for contiguous gaps, deterministic bridge
     reconstruction, Brownian bridge samples, and downstream diagnostics.
   - Generated by `src/plot_uncertainty_framework_figure.py`.

2. `missing_data_stability.png`
   - Random point loss versus contiguous tracking gap stability diagnostics.
   - Generated by `src/plot_missing_data_stability.py`.

3. `brownian_bridge_gap_reconstruction_batch.png`
   - Season-aware Brownian bridge reconstruction diagnostics across gap
     fractions, metrics, and seasons.
   - Generated by `src/plot_brownian_bridge_batch.py`.

Additional diagnostic figures may be regenerated from scripts in `src/` when
needed, but they are not part of the current main manuscript package.
